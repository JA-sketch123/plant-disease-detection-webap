# Plant Disease Detection Web Application

## Overview
The Plant Disease Detection Web Application is an AI-powered system that detects plant diseases using Deep Learning and Computer Vision techniques. The project uses a Convolutional Neural Network (CNN) model based on EfficientNetB3 with TensorFlow and Keras to classify plant diseases from uploaded images.

The application provides a user-friendly web interface where users can upload plant images and receive disease predictions along with prevention suggestions.

## Features
- Plant disease detection using Deep Learning
- CNN model trained using TensorFlow & Keras
- EfficientNetB3 transfer learning model
- Image-based disease prediction
- User-friendly web interface
- Prevention and treatment suggestions

## Deep Learning Model
The project uses EfficientNetB3, a pre-trained Convolutional Neural Network model with transfer learning for accurate plant disease classification.

### Model Features
- Transfer Learning using ImageNet weights
- Data Augmentation for better generalization
- Fine-tuning of model layers
- Early Stopping to reduce overfitting
- Model Checkpointing for saving the best model

## Dataset
The model was trained on a plant disease image dataset containing multiple categories of healthy and diseased plant leaves.
